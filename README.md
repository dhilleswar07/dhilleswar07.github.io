# Dhilleswar Jogi — Portfolio

A responsive Data Science + AI/ML portfolio website.

## Files
- `index.html` — portfolio page
- `style.css` — responsive dark/green visual design
- `script.js` — mobile navigation and live GitHub repository loading
- `dhilleswar-profile.jpeg` — profile photo supplied by Dhilleswar

## Run locally
Open `index.html` in a browser, or use VS Code + Live Server.

## Projects
The portfolio contains featured projects and automatically loads all public repositories from `https://api.github.com/users/dhilleswar07/repos` when the page is opened online.

## Publish
You can deploy this folder to GitHub Pages, Netlify, or Vercel.
